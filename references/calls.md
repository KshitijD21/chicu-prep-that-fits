# Reminders and calls

Read this when the student asks about reminders or calls, or before offering a reminder.
Calendar approval, reminder approval and call approval are separate decisions.

## Text reminders

Show exact dates, times, time zone, frequency and end date before creating the approved schedule.
Each later task must name Interview Sprint, the block/question, what to check and how to reply,
so it makes sense without the current chat. Do not create recurring tasks from calendar approval.
Verify the saved schedule before saying it is active.

## Conditional-call safeguard

The default is **disabled**. Enable conditional calls for a student only after a real test
establishes all of the following for the intended condition:

1. A later task can inspect the correct completion messages and evaluate the agreed condition.
2. One authorized test call actually executes when the no-completion condition is satisfied.
3. Completion before the agreed cutoff suppresses a separately authorized test call.
4. Cancellation removes the call and any associated condition check.

A claim of support, a scheduled fixed-time call or an absent call alone does not establish these
behaviors. With consent to saving settings, record the observed support, date and limitations.
After all checks pass, the state can become verified for that tested mechanism; the default
restriction no longer blocks that mechanism. New conditions still need their own support check.
Verification is capability evidence, not standing authorization to call.

If any check fails or remains unverified, keep conditional calls disabled and offer a separately
approved text check-in. A fixed-time interview-morning call is a separate capability: verify its
scheduling and delivery support before use; it does not establish conditional-call support.

## Exact authorization

For each call or limited call schedule, preview:

- The event or explicit completion phrase and how the later task will check it.
- The cutoff, grace period, check time and call time, with exact dates and time zone.
- At most one call per authorized occurrence, the overall count cap and expiration.
- The spoken message and cancellation instructions.

Use an observable definition such as "no explicit completion text by the agreed cutoff";
an absent reply alone does not prove the student skipped practice. Keep time-sensitive calls
blocked when dates or conditions are ambiguous. Get an explicit yes to the exact preview,
then verify creation. If creation fails, report that instead of claiming a call is scheduled.
Use a harmless near-future test before relying on the mechanism for a real interview.

## Delivery and cancellation

Calls are one-way spoken reminders; the student replies by text. An unanswered call or silence
grants no approval, changes no calendar events and triggers no additional calls.
A follow-up text is allowed only within the approved check-in's scope.

Honor "stop reminders" or "cancel the call" immediately for the specified Interview Sprint tasks.
Verify cancellations, including condition checks, and report any remaining task or failure.
Do not cancel unrelated reminders or contact another person.
